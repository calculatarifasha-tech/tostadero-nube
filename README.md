# Tostadero Nube · Landing page demo

Responsive landing page for a **fictional** specialty coffee shop in Granada, built as a portfolio demo.

- Hero with call to action, features, tabbed menu, reviews, opening hours and booking form
- Mobile menu, scroll-reveal animations (respecting `prefers-reduced-motion`) and client-side form validation
- Plain HTML, CSS and JavaScript in a single file — no frameworks, no build step

**Live demo:** see the GitHub Pages link in the repository's About section.

> Business name, address, prices and reviews are fictional. The booking form does not send any data.
